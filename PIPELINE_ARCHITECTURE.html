Architecture reference — NamaSys lead-gen pipeline

Who does what, and how it's wired together

Fourteen Python scripts, one Claude Managed Agent, and three external systems (Apollo, HubSpot, Gmail) — this maps every hop: which parts are the agent reasoning, which are plain deterministic code, and which protocol connects each pair (MCP, the Anthropic Sessions API, REST, or SMTP).

From main.py to the SDR's inbox

The automatic part. Two independent Agent sessions do all the searching, enrichment, and scoring against Apollo — but the agent only ever talks to Apollo through MCP tool calls. Everything below the agent's final answer is plain Python.

After the human reads the CSV: two separate, gated paths

Nothing past the SDR's inbox happens automatically. Both destinations below require a typed y — and they're independent: run one, both, or neither.
